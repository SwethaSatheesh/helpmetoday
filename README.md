# HelpMeToday Mobile App

Early iOS and Android prototype for HelpMeToday, built with Expo and React Native.

## Run It

```sh
npm start
```

Then open the app in one of these ways:

- Scan the Expo QR code with Expo Go on your phone.
- Press `i` in the Expo terminal for iOS Simulator.
- Press `a` in the Expo terminal for Android Emulator.

## Built Today

- Created the Expo React Native project.
- Added the HelpMeToday logo as an app asset.
- Built a branded mobile prototype with Start, Home, Job, Earnings, and Profile tabs.
- Matched the current mockup direction: warm cream background, forest green CTAs, worker dashboard cards, job progress, OTP, earnings, documents, and profile sections.
